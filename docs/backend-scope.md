# 服務層設計（原 tianxi-football-backend）

> 2026-10-06 起併入統一倉 `tianxi-football`；原倉已封存。
> 註：實際生產服務層（凍結鎖定、帳本結算、公開 API）現運行於天喜應用後端
> （`src/routes/api/`），本文件保留原分層設計與鐵律。

## 職責
- Elo / pi-rating 逐場迭代更新（禁止全歷史重擬合，跨季回歸 `Elo_next = R×0.75 + 0.25×聯盟平均`）
- Poisson / Dixon-Coles 攻防參數擬合 → 比分分布 → 1X2 邊際
- LGB 推理、α 集成（`blendZ = α·lgbZ + (1−α)·eloZ`）、Platt／isotonic 校準
- 紅黃綠燈鎖定 API：T−6h 鎖定（綠）→ 賽後對帳；快照存指紋＋凍結時間
  （2026-10-06 前舊場次為 T−60，歷史帳不改）
- admin 分析端點（只限內部頁）

## 鐵律
- `market_beta = 0`：賠率只作基準線、離線對照軌、殘差診斷，永不進入排名
- 凍結範圍連「揀邊個盤口」規則一齊凍結並公示
- 所有歷史預測公開，包括差的預測同虧損期，不刪不改

生產服務層已於天喜應用後端運行（dual-v1 雙引擎帳本、T−6h 鎖定、model_versions 版本登記）。
